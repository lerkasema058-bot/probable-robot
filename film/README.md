# Марк и Ваня — новогодний мини-фильм

Готовые ролики по промпт-сценарию, в двух форматах:

| Файл | Формат | Длительность | Размер |
|------|--------|--------------|--------|
| **`new_year_brothers.mp4`** | 1920×1080 (16:9) | 60 сек | ~20 МБ |
| **`new_year_brothers_vertical.mp4`** | 1080×1920 (9:16) | 60 сек | ~19 МБ |

30 fps, H.264 + AAC, со закадровым голосом, музыкой и финальным титром.
Раскадровки: `storyboard.jpg` (16:9) и `storyboard_vertical.jpg` (9:16).


## «Живая» версия (дети двигаются)

Помимо «кадровой» версии есть полноценная анимированная:

| Файл | Формат | Длительность | Размер |
|------|--------|--------------|--------|
| **`new_year_brothers_live.mp4`** | 1920×1080 | 57 сек | ~15 МБ |
| **`new_year_brothers_live_vertical.mp4`** | 1080×1920 | 57 сек | ~15 МБ |
| `live_preview.mp4` | 1920×1080 | 17 сек | ~4.6 МБ — короткое превью движения |

Как сделано движение: для каждой сцены сгенерированы **3 ключевых кадра с одинаковой композицией и разными позами** (Марк тянется, поднимает игрушку, обнимает; Ваня хлопает, машет, прижимается). Между ними ffmpeg `minterpolate` (motion-compensated interpolation, режим bidir + aobmc) строит промежуточные кадры — руки, головы и корпус реально смещаются, без «слайд-шоу». Позы лежат в `motion/`.

Ограничение честно: это интерполяция между фото, а не сгенерированное видео. Движение плавное и естественное по формам, но это не свободные действия вроде бега по комнате — амплитуда ограничена разницей между ключевыми кадрами. Для полностью «живых» сцен нужен image-to-video генератор (Runway, Kling, Veo, Pika): те же кадры из `frames/` и `motion/` подойдут как референсы, а сценарий и тайминги — из этого README.

Пересборка живой версии:

```bash
node film/render-motion.mjs            # 16:9
FORMAT=v node film/render-motion.mjs   # 9:16
```

## Титр

Финальные 8 секунд — нежный титр в кадре: «С Новым годом!» (шрифт Cormorant Garamond 600, тёплое золото) и подпись «Марк и Ваня» с тонкой линией-разделителем и мягким свечением. Появляется плавно, поверх огоньков ёлки, с лёгкой тёмной вуалью для читаемости. Файл шрифта: `fonts/CormorantGaramond.ttf` (SIL Open Font License).

## Стиль и техника

- Мягкий тёплый грейд (тёплые света, холодные тени от окна), виньетка, плёночное зерно.
- Чередование общих планов и крупных планов рук и улыбок — по сценарию.
- Плавный «Ken Burns» (медленный наезд/отъезд) и наплывы 0.7 с между планами.
- Снег на переднем плане в три слоя глубины.
- **Музыка** (`make-music.mjs`, генерируется локально, без сэмплов): «музыкальная шкатулка» + мелодия глокеншпиля + мягкий бас и **бубенцы**; гармония C–Am–F–G, 76 BPM. Автоматически приглушается под голосом (ducking по огибающей речи).
- Безопасность: только крупные небьющиеся украшения, никаких свечей, бенгальских огней и пиротехники в кадре.

## Пересборка

Нужны `ffmpeg` и `@napi-rs/canvas`:

```bash
npm i --no-save @napi-rs/canvas
FF=/path/to/ffmpeg node film/render.mjs            # 16:9
FORMAT=v FF=/path/to/ffmpeg node film/render.mjs   # 9:16
```

Скрипт сам озвучивает таймлайн, генерирует музыку, рисует все кадры, кодирует видео и муксит финальный mp4. Кадры (`frames/`) и озвучка (`audio/`) — исходники, их можно заменить своими.
