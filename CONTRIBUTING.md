# Как помочь проекту (Contributing)

Спасибо за интерес к развитию **probable-robot (Kids Studio)**!

## Требования к окружению

- **Node.js** `>= 22.13` и `npm`
- Современный браузер с поддержкой `HTMLCanvasElement.captureStream`, `MediaRecorder` и `Web Audio API`

## Локальная разработка

1. Форкните репозиторий и клонируйте его локально.
2. Установите зависимости:
   ```bash
   npm ci
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
4. Создайте ветку для своей задачи (например, `feat/new-kids-bg` или `fix/subtitle-wrap`).

## Архитектура и правила кода

- **`src/data.js`** — декларативные справочники фонов, героев, стикеров, моделей и шаблонов.
- **`src/renderer.js`** — чистая детерминированная отрисовка кадра по прогрессу `t ∈ [0..1]`.
  - Не используйте `Math.random()` или `Date.now()` внутри цикла отрисовки — используйте `seededRandom()` из `src/utils.js` и время `t`, чтобы кадры в экспорте не мерцали.
  - Не передавайте CSS-переменные (`var(--...)`) в `CanvasRenderingContext2D` — используйте явные цвета.
- **`src/storage.js` / `src/utils.js`** — все координаты персонажей и штрихов кисти хранятся в нормализованном виде (`nx`, `ny`, `nSize` в диапазоне `0..1`), чтобы переключение форматов `16:9` / `9:16` / `1:1` не искажало сцену.
  - Ключи `localStorage` имеют префикс `pr-*` (см. `STORAGE_KEYS` в `src/storage.js`).
  - Текущая версия схемы экспортируемых черновиков `.json` — `v: 3` (с обратной совместимостью с `v: 2` через `validateProject()`).
  - При работе с пользовательскими данными из `.json` и именами файлов используйте `textContent` вместо `innerHTML` и проверяйте изображения через `isSafeImageDataUrl()`.

## Проверки перед отправкой Pull Request

Перед открытием PR убедитесь, что все проверки проходят без ошибок:

```bash
npm run lint
npm test
npm run build
```

Вопросы и предложения — в разделе [GitHub Issues](https://github.com/lerkasema058-bot/probable-robot/issues).
