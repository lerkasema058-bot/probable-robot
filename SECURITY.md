# Политика безопасности (Security Policy)

## Поддерживаемые версии

Актуальные обновления безопасности выпускаются для ветки `main` (версия `0.2.x` и новее).

## Как сообщить об уязвимости

Пожалуйста, **не публикуйте** детали уязвимостей в открытых GitHub Issues до выхода исправления.

Для конфиденциальной отправки отчёта используйте встроенный механизм GitHub:

1. Откройте вкладку **[Security](https://github.com/lerkasema058-bot/probable-robot/security)** этого репозитория.
2. Нажмите **Report a vulnerability** (Private Vulnerability Reporting) и опишите шаги воспроизведения, затронутые файлы и потенциальное влияние.

Если функция приватных отчётов недоступна для вашего аккаунта, свяжитесь с владельцем репозитория через профиль GitHub [@lerkasema058-bot](https://github.com/lerkasema058-bot) с пометкой `SECURITY`, не раскрывая эксплойт публично.

Мы постараемся подтвердить получение отчёта в течение 72 часов и выпустить исправление в кратчайшие сроки.
