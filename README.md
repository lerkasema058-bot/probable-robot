# probable-robot — Студия видео для детей (Kids Studio)

> Создавай яркие мультяшные и реалистичные видеоролики из текста, персонажей, фотографий, рисунков и музыки прямо в браузере. Без серверов, без регистрации, работает офлайн как PWA.

![video generator](https://img.shields.io/badge/Kids_Studio-video_generator-ff2d55?style=for-the-badge)
![license](https://img.shields.io/badge/license-MIT-green)

**Быстрый запуск:** выполни `npm install && npm run dev` и открой `http://localhost:5173`

---

## Что это умеет

### 🎈 Детская студия (`Дети`)
- **2 визуальных режима:** **Мультяшный** (яркие сказочные иллюстрации, облака, замок, космос) и **Реалистичный** (саванна, горы, океан, лес для познавательных роликов).
- **14 процедурных фонов сцены** с плавной детерминированной анимацией на Canvas.
- **Персонажи и анимированные стикеры:** перетаскивание мышью/пальцем, изменение размера колесом мыши или кнопками `+`/`−`, управление с клавиатуры (стрелки + `Delete`).
- **Свои фото (ребёнок / питомец):** загрузка нескольких фото с автоматическим сжатием до оптимального размера (без переполнения памяти браузера) и отображением в аккуратном круге на сцене.
- **Кисть для рисования:** свободное рисование мышью или пальцем поверх сцены с выбором цвета и толщины.
- **Синтезатор музыки (Web Audio API):** 3 мелодических пресета (*Весёлая*, *Сказочная*, *Энергичная*), предпрослушивание и сведение в единый видеофайл вместе с картинкой.
- **Детские эффекты и готовые истории:** конфетти, пузырьки, облачка с репликами героев и 8 готовых сюжетных шаблонов (*День Рождения, Азбука, Сказка, Животные Африки, Космос* и др.).

### 📝 Генератор текста и пресеты (`Текст` + `Модель`)
- Заголовок и многострочный подзаголовок с автоматическим переносом слов и озвучкой текста (**Web Speech API** `ru-RU`).
- **3 формата кадра** без потери позиций и пропорций сцены: **16:9** (`1280×720`), **9:16** (`720×1280` Stories/Reels), **1:1** (`800×800`).
- **6 стилей-моделей:** *Классика, Кино, Неон, Минимализм, Типографика, Распродажа*.
- **5 типов анимации текста:** плавное появление, печатная машинка, выезд снизу, зум, без анимации.
- **Черновики и автосохранение:** локальное сохранение при изменениях, экспорт и безопасный импорт проектов `.json` (версия схемы `v: 3`).
- **Экспорт:** скачивание записанного видео (`webm`/`mp4` в зависимости от браузера) и быстрый экспорт текущего кадра в PNG.
- **PWA / Офлайн-режим:** устанавливается на телефон или компьютер через `manifest.json` + Service Worker (`sw.js` со стратегией network-first и офлайн-кэшем).

## Быстрый старт

Требуется **Node.js >= 22.13**.

```bash
# 1. Установка зависимостей
npm install

# 2. Режим разработки с горячей перезагрузкой
npm run dev

# 3. Проверка кода (ESLint) и запуск тестов (Vitest)
npm run lint
npm test

# 4. Сборка для продакшена в папку dist/
npm run build

# 5. Локальная проверка собранной версии
npm run preview
```

Деплой поддерживает как корень домена (`/`), так и подпапки (например, GitHub Pages), так как сборка настроена с `base: './'`.

## Совместимость с браузерами

- **Chrome / Edge / Firefox (Desktop & Android):** запись в `.webm` (`VP9` / `VP8` + `Opus`) со звуком и 30 кадр/сек.
- **Safari / iOS (14.5+):** автоматический выбор поддерживаемого контейнера `video/mp4` (`H.264` / `AAC`) в `MediaRecorder`.
- Все вычисления выполняются локально в браузере (`Canvas 2D` + `MediaRecorder` + `Web Audio API`), фотографии и видео никуда не отправляются.

## Инструменты для видео (CLI)

В репозитории есть helper-скрипт для конвертации/скачивания производных видеофайлов через `ffmpeg`:

```bash
# WebM/MOV -> MP4
scripts/video-tools.sh mp4 input.webm output.mp4

# Видео -> GIF
scripts/video-tools.sh gif input.mp4 output.gif

# Извлечь аудио
scripts/video-tools.sh audio input.mp4 output.mp3

# Изменить размер
scripts/video-tools.sh resize input.mp4 1280 720 output.mp4

# Сжать
scripts/video-tools.sh compress input.mp4 output.mp4
```

> Если `ffmpeg` не установлен в системе, скрипт попробует использовать бинарь из `imageio-ffmpeg` (`pip install imageio-ffmpeg --break-system-packages`).

## Известные ограничения

- **Запись видео** зависит от `MediaRecorder` и `canvas.captureStream`: в Chrome/Edge/Firefox обычно доступен `webm`, в Safari/iOS — `mp4` (если поддерживается браузером).
- **Черновики с фото** хранятся в `localStorage`; большие изображения автоматически сжимаются при загрузке, но при переполнении хранилища нужно экспортировать проект в `.json`.
- **Офлайн/PWA**: после первой загрузки приложение кэширует shell и запрошенные ресурсы; для полностью воспроизводимого офлайна после новой сборки лучше обновить Service Worker/кэш.
- **CLI-конвертация (ffmpeg)**: в окружении можно использовать `ffmpeg` (в этом sandbox он доступен через `imageio-ffmpeg`); для локальной машины установите `ffmpeg` отдельно.
