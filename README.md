# probable-robot — Генератор видео

> Создавай видео из текста за 10 секунд прямо в браузере. Без серверов, без регистрации.

![video generator](https://img.shields.io/badge/video-generator-ff2d55?style=for-the-badge)
![license](https://img.shields.io/badge/license-MIT-green)

**Живая демо:** запусти `npm run dev` и открой `http://localhost:5173`

## Что это умеет

- **Генерировать видео** из заголовка + подзаголовка (webm, 2–10 сек)
- 3 формата: **16:9** (YouTube/горизонт), **9:16** (Stories/Reels), **1:1** (посты)
- Фоны: градиенты, сплошной цвет, **своя картинка** (drag & drop)
- Анимации: печатная машинка, зум, слайд, плавное появление
- Частицы, Ken Burns, водяной знак
- **Всё в браузере** — Canvas + MediaRecorder, ничего не улетает на сервер
- **6 моделей-пресетов** (вкладка «Модель»): Классика, Кино (зерно + чёрные полосы), Неон, Минимализм, Типографика, Распродажа
- Скачивание `.webm` (в Safari — `.mp4`) — открывается в Telegram, WhatsApp, Instagram, на телефоне

## Быстрый старт

```bash
# 1. Установка
npm install

# 2. Запуск (откроется превью)
npm run dev

# 3. Сборка для продакшена
npm run build
```

Открой `http://localhost:5173`, введи текст, выбери фон и нажми **Сгенерировать видео**.

> Превью-среда работает через внешний прокси-домен, поэтому в `vite.config.js` включены
> `host: true` и `allowedHosts: true`. Без `allowedHosts` dev-сервер отдаёт **403 Blocked request**
> и страница не открывается вообще (кнопки «не работают» именно по этой причине).

## Как генерировать видео — шаг за шагом

1. Введи **заголовок** и **подзаголовок** слева.
2. Выбери **фон**: градиент, цвет или загрузи свою картинку (можно перетащить на превью).
3. Выбери **формат** (9:16 для сторис, 16:9 для ютуба) и **анимацию**.
4. Нажми **Сгенерировать видео** → скачается файл `.webm`.
5. Выкладывай куда хочешь. Если нужен `.mp4` — конвертируй через любой онлайн-конвертер webm→mp4 (1 клик).

## Шаблоны

Справа — готовые шаблоны (Скидка, Новинка, Акция и т.д.). Кликни чтобы применить, затем поменяй текст под себя.

## Модели

Вкладка **Модель** в левой панели — это пресеты стиля, а не «нейросети в облаке»:
каждая модель меняет фон, анимацию, частицы, цвет текста и затемнение, и применяется мгновенно.
Выбор сохраняется в `localStorage` и используется при генерации.

## Если кнопка «Сгенерировать видео» не срабатывает

Приложение пишет причину в строку статуса под превью:

- «Этот браузер не умеет записывать видео с canvas…» — нет `MediaRecorder`/`captureStream`
  (старый Safari, встроенный браузер Telegram/Instagram). Открой в Chrome, Edge, Firefox или Safari 15+.
- «Браузер не поддерживает запись видео…» — не нашлось ни одного поддерживаемого формата.
- «Не получилось записать видео: …» — смотри текст ошибки (часто помогает уменьшить длительность).
- «Ошибка отрисовки: …» — ошибка Canvas; теперь она показывается, а не глотается молча.

## Технологии

- Vanilla JS + HTML5 Canvas + MediaRecorder API
- Vite (dev server + build)
- Чистый CSS, без фреймворков
