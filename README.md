# probable-robot — Генератор видео

> Создавай видео из текста за 10 секунд прямо в браузере. Без серверов, без регистрации.

![video generator](https://img.shields.io/badge/video-generator-ff2d55?style=for-the-badge)
![license](https://img.shields.io/badge/license-MIT-green)

**Живая демо:** запусти `npm run dev` и открой `http://localhost:5173`

## Что это умеет

- **Генерировать видео** из заголовка + подзаголовка (webm, 2–10 сек)
- 3 формата: **16:9** (YouTube/горизонт), **9:16** (Stories/Reels), **1:1** (посты)
- Фоны: градиенты, сплошной цвет, **своя картинка** (drag & drop)
- Анимации: печатная машинка, зум, слайд, плавное появление
- Частицы, Ken Burns, водяной знак
- **Всё в браузере** — Canvas + MediaRecorder, ничего не улетает на сервер
- Скачивание `.webm` — открывается в Telegram, WhatsApp, Instagram, на телефоне

## Быстрый старт

```bash
# 1. Установка
npm install

# 2. Запуск (откроется превью)
npm run dev

# 3. Сборка для продакшена
npm run build
```

Открой `http://localhost:5173`, введи текст, выбери фон и нажми **Сгенерировать видео**.

## Как генерировать видео — шаг за шагом

1. Введи **заголовок** и **подзаголовок** слева.
2. Выбери **фон**: градиент, цвет или загрузи свою картинку (можно перетащить на превью).
3. Выбери **формат** (9:16 для сторис, 16:9 для ютуба) и **анимацию**.
4. Нажми **Сгенерировать видео** → скачается файл `.webm`.
5. Выкладывай куда хочешь. Если нужен `.mp4` — конвертируй через любой онлайн-конвертер webm→mp4 (1 клик).
