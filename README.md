# probable-robot — Студия видео для детей (Kids Studio)

> Создавай яркие мультяшные и реалистичные видеоролики из текста, персонажей, фотографий, рисунков и музыки прямо в браузере. Без серверов, без регистрации, работает офлайн как PWA.

## Что это умеет

### 🎈 Детская студия (`Дети`)
- **2 визуальных режима:** **Мультяшный** (яркие сказочные иллюстрации, облака, замок, космос) и **Реалистичный** (саванна, горы, океан, лес для познавательных роликов).
- **14 процедурных фонов сцены** с плавной детерминированной анимацией на Canvas.
- **Персонажи и анимированные стикеры:** перетаскивание мышью/пальцем, изменение размера колесом мыши или кнопками `+`/`−`, управление с клавиатуры (стрелки + `Delete`).
- **Свои фото (ребёнок / питомец):** загрузка нескольких фото с автоматическим сжатием до оптимального размера (без переполнения памяти браузера) и отображением в аккуратном круге на сцене.
- **Кисть для рисования:** свободное рисование мышью или пальцем поверх сцены с выбором цвета и толщины.
- **Синтезатор музыки (Web Audio API):** 3 мелодических пресета (*Весёлая*, *Сказочная*, *Энергичная*), предпрослушивание и сведение в единый видеофайл вместе с картинкой.
- **Детские эффекты и готовые истории:** конфетти, пузырьки, облачка с репликами героев и 8 готовых сюжетных шаблонов (*День Рождения, Азбука, Сказка, Животные Африки, Космос* и др.).

### 🤖 ИИ-агент (`Агент`)
- **Агент-режиссёр:** опиши ролик словами («видео на день рождения для Саши, космос, 9:16, 8 секунд, весёлая музыка») — агент сам соберёт сцену: шаблон, фон, героев, текст, формат, длительность, музыку и эффекты.
- **Два мозга:** 🧠 **локальный** (офлайн, разбирает русские фразы по ключевым словам и каталогу студии, без ключей) и **OpenAI-совместимый API** (любой endpoint с поддержкой tool calls: указываешь base URL, модель и ключ, ключ хранится только в `localStorage`).
- **Генерация изображений нейросетью:** по фразе «нарисуй закат над морем» или «сгенерируй героя единорога» агент создаёт фон или круглого героя через OpenAI-совместимый `/images/generations` (модель задаётся в настройках, по умолчанию `gpt-image-1`). Картинка сжимается до 1440 px и сохраняется в черновике — работает офлайн.
- **Загрузка своих фото:** по просьбе «добавь фото ребёнка» агент показывает кнопку выбора файлов — выбранные фото сжимаются и становятся героями сцены. Файлы никуда не отправляются.
- **19 инструментов** с валидацией аргументов: текст, фон, модель/стиль, генерация картинок, герои и стикеры, фото, формат, анимация, длительность, музыка, эффекты, готовые истории/шаблоны, озвучка и запуск записи видео.
- **План перед применением:** по умолчанию агент применяет шаги сразу, но можно выключить «Применять сразу» — тогда появится карточка плана с кнопками «✅ Применить» / «✕ Отмена».
- **Безопасность:** всё исполняется локально в браузере, текст sanitize-ится, цвета и идентификаторы валидируются по каталогу, недопустимые аргументы возвращают ошибку, а не ломают сцену.

### 📝 Генератор текста и пресеты (`Текст` + `Модель`)
- Заголовок и многострочный подзаголовок с автоматическим переносом слов и озвучкой текста (**Web Speech API** `ru-RU`).
- **3 формата кадра** без потери позиций и пропорций сцены: **16:9** (`1280×720`), **9:16** (`720×1280` Stories/Reels), **1:1** (`800×800`).
- **6 стилей-моделей:** *Классика, Кино, Неон, Минимализм, Типографика, Распродажа*.
- **5 типов анимации текста:** плавное появление, печатная машинка, выезд снизу, зум, без анимации.
- **Черновики и автосохранение:** локальное сохранение при изменениях, экспорт и безопасный импорт проектов `.json` (версия схемы `v: 3`).
- **PWA / Офлайн-режим:** устанавливается на телефон или компьютер через `manifest.json` + Service Worker (`sw.js` со стратегией network-first и офлайн-кэшем).

## Быстрый старт

Требуется **Node.js >= 22.13**.

```bash
# 1. Установка зависимостей
npm install

# 2. Режим разработки с горячей перезагрузкой
npm run dev

# 3. Проверка кода (ESLint) и запуск тестов (Vitest)
npm run lint
npm test

# 4. Сборка для продакшена в папку dist/
npm run build

# 5. Локальная проверка собранной версии
npm run preview
```

Деплой поддерживает как корень домена (`/`), так и подпапки (например, GitHub Pages), так как сборка настроена с `base: './'`.

### 🤖 Как запустить ИИ-агента

Агент уже встроен в приложение — отдельный сервис не нужен.

1. Открой приложение (`npm run dev` → `http://localhost:5173`) и перейди во вкладку **🤖 Агент**.
2. Напиши ролик своими словами или нажми готовый пример-чип. По умолчанию агент применяет план сразу.
3. Хочешь проверять шаги — сними галочку «Применять сразу»: появится план с кнопками «✅ Применить» / «✕ Отмена».

**Локальный мозг** (по умолчанию) работает офлайн и без ключей. Чтобы подключить настоящую LLM:

1. В блоке «🧠 Мозг агента» выбери **OpenAI-совместимый API**.
2. Укажи `Base URL` (например, `https://api.openai.com/v1`), модель и API-ключ.
3. Нажми **🔌 Проверить соединение** — агент отправит тестовый запрос и покажет ответ модели.

Ключ хранится только в `localStorage` браузера и уходит напрямую в указанный endpoint; на серверы студии ничего не отправляется. Endpoint должен разрешать запросы из браузера (CORS) — подойдут Ollama, LM Studio, OpenRouter или собственный прокси.

Примеры команд агенту:

```text
Видео на день рождения для Саши, 9:16, 8 секунд, весёлая музыка
Мультяшный ролик про котика и лисичку в лесу, 5 секунд
Космос с единорогом и ракетой, неон, 6 секунд, без музыки
Скидка 30% на корм для котов, неон, 9:16, 5 секунд, энергичная музыка
нарисуй закат над морем, 6 секунд                      ← генерация фона
сгенерируй героя единорога в космосе, 5 секунд         ← генерация героя
добавь фото ребёнка и сделай день рождения             ← загрузка своих фото
```

**Генерация картинок** (`нарисуй…`, `сгенерируй…`) требует API-ключ и модель с поддержкой `/images/generations` — поле «Модель картинок» в настройках агента. Без ключа инструмент честно вернёт ошибку, а сцена не сломается.

**Свои фото:** браузер не даёт выбрать файл без клика пользователя, поэтому агент показывает карточку с кнопкой «📸 Выбрать фото». Файлы обрабатываются локально и никуда не отправляются.

## Совместимость с браузерами

- **Chrome / Edge / Firefox (Desktop & Android):** запись в `.webm` (`VP9` / `VP8` + `Opus`) со звуком и 30 кадр/сек.
- **Safari / iOS (14.5+):** автоматический выбор поддерживаемого контейнера `video/mp4` (`H.264` / `AAC`) в `MediaRecorder`.
- Все вычисления выполняются локально в браузере (`Canvas 2D` + `MediaRecorder` + `Web Audio API`), фотографии и видео никуда не отправляются.

```text
│   ├── utils.js               # Нормализация координат, перенос строк, сжатие фото, санитизация

│   ├── manifest.json          # Манифест веб-приложения (PWA)
│   ├── sw.js                  # Service Worker (network-first + офлайн-кэш)
│   └── icon.svg               # Иконка приложения
├── tests/                     # Модульные тесты (Vitest + JSDOM)
├── eslint.config.js           # Конфигурация ESLint
├── vite.config.js             # Конфигурация Vite и Vitest
└── .github/workflows/ci.yml   # CI: lint + test + build
```
