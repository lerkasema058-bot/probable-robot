Готов к работе

🧠 Мозг агента

Ключ лежит только в localStorage этого браузера и уходит напрямую в указанный endpoint.
Можно оставить Base URL пустым — подставится https://api.openai.com/v1.
Модели (обычно менять не нужно)
gpt-4o-mini — текст и инструменты. Картинки генерирует gpt-image-1 (или dall-e-3).
Генерация фонов и героев идёт в /images/generations — этот метод есть не у всех провайдеров.
Endpoint должен разрешать запросы из браузера (CORS).
Где взять ключ и что вписать?
  • OpenAI: Base URL https://api.openai.com/v1, модель gpt-4o-mini, модель картинок gpt-image-1. Ключ — на platform.openai.com/api-keys.
  • LocalAI или свой шлюз: Base URL вроде http://localhost:8080/v1, ключ любой, модели — какие развёрнуты.
  • Прокси (one-api / new-api): Base URL вашего шлюза, ключ выдаёт сам шлюз.
Если метода картинок у провайдера нет — генерация фонов вернёт ошибку, остальной агент продолжит работать.
Локальный мозг понимает русские команды и работает без интернета.

Шаблоны — нажми чтобы применить

Для детей: перейди во вкладку 🎈 Дети — там фоны, герои и 8 готовых историй (День рождения, Азбука, Сказка, Космос...).

Как монтировать крутые видео для детей

Мультяшные — яркие фоны (небо, лес, замок, космос) + милые герои (мишка, лиса, единорог) + конфетти.

Реалистичные — природа и животные как в жизни (саванна, лес, океан) — для познавательных видео.

  • 1. Вкладка 🤖 Агент → опиши ролик словами: «видео на день рождения для Саши, космос, 9:16, 8 секунд, весёлая музыка» — сцена соберётся сама
  • 2. Или вручную: вкладка 🎈 Дети → выбери стиль (мультяшный/реалистичный)
  • 3. Выбери фон сцены → клик по герою добавит его на сцену
  • 4. На сцене перетаскивай мышкой, крути колесом для размера или двигай стрелками
  • 5. Введи текст в «Текст», выбери формат 9:16 для телефона
  • 6. Нажми Сгенерировать видео → скачай ролик

Все герои рисуются на Canvas и попадают в видео вместе с музыкой и рисунком кистью.
